# Skill: new-controversia

Create a new Controversia (cultural debate) entry for the acho.lol encyclopedia.

## Instructions

1. Ask the user for:
   - The debate topic
   - The opposing positions
   - Any context, references, or hot takes to include

2. Create the file at `Controversias/{title}.md` with this structure:

```markdown
---
title: "{title}"
tags:
  - controversias
  - (topic tags: comida, politica, regional, deportes, etc.)
---

> [!WARNING] Esta página está incompleta. #wip

(Intro paragraph framing the debate)

## Las posiciones

(Present the different sides — be fair but funny)

## El contexto

(Background, history, why this matters)

## Véase también

- [[Related Entry 1]]

## Referencias

- (Sources, articles, tweets, etc.)
```

3. After creating the file:
   - Link from any related entries
   - Use `> [!WARNING]` for unverified claims
   - If the controversy involves specific terms or people, link to their entries

## Guidelines

- Present all sides — this wiki documents, it doesn't take sides (well, sometimes it does, jocosely)
- Mark unverified information clearly
- Include references where possible
- The question mark format (¿...?) is preferred for titles: `¿Empanadilla o pastelillo?.md`
- Write in informal Puerto Rican Spanish
